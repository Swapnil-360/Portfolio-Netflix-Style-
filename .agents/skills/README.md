## Installed Workspace Skills

1. **`human-design-review`**: Enforces human design standards, anti-generic UI checks, and multi-viewport visual audits.
2. **`frontend-design`**: Tokens, typography hierarchy, SaaS component patterns, and responsive design systems.
3. **`motion-design`**: Framer Motion physics, easing curves, layout transitions, and reduced-motion safety.
4. **`browser-testing`**: Playwright automation scripts, responsive breakpoint verification, and console error audits.
5. **`production-audit`**: Static typecheck, accessibility (WCAG), client-side security checks, and bundle budgets.
6. **`coderabbit-review`**: Independent CodeRabbit CLI review gate, severity categorization, and false-positive filtering.
7. **`coderabbit-autofix`**: Targeted resolution of CodeRabbit review comments and pull request suggestions.
