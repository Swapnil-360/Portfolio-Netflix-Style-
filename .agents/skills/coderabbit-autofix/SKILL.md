# CodeRabbit Autofix & Comment Resolution

This skill processes review feedback generated by CodeRabbit on active pull requests or local reviews.

## 1. Resolution Protocol

1. **Ingest Feedback:** Read CodeRabbit suggestions or fetch review comments via GitHub CLI (`gh pr view --comments`).
2. **Feasibility Analysis:**
   - Does the suggestion align with project rules in [`AGENTS.md`](../../AGENTS.md)?
   - Does it break existing architecture or dependencies?
3. **Targeted Application:**
   - Apply edits atomically to the specific lines cited.
   - Run `npm run build` after each fix.
4. **Resolution Confirmation:**
   - Document each resolved finding with its before/after diff summary.
